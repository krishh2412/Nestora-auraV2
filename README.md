# Aura v2
Aura is the fitness, habits, recovery and personal-performance companion to Nestora.

## v2 additions
- Daily Quests with XP and leveling
- Streaks and achievements
- Optional Hard Mode
- Motivational card experience
- Existing workout, habits, recovery, body progress, plans, Hanuma and Nestora calendar bridge preserved
- Cloud persistence for quest/player state
- Idempotent Aura -> Nestora calendar migration to remove duplicates
- GitHub -> Vercel build configuration included

See `DEPLOYMENT_STEPS.md` for the exact deployment order.
